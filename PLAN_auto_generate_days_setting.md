# План: Настройка автогенерации дней в месяце

**Цель:** Добавить в настройки выбор дней недели, которые автоматически создаются при открытии нового месяца.  
По умолчанию — пятница и суббота (текущее поведение сохраняется).

## Шаг 1 — `AppSettings.cs`: добавить свойство

**Файл:** `Infrastructure/Settings/AppSettings.cs`

Добавить после `MinimumHours`:

```csharp
public List<DayOfWeek> AutoGenerateDays { get; set; } =
    [DayOfWeek.Friday, DayOfWeek.Saturday];
```

Хранится в JSON как массив целых чисел (0=Sunday … 6=Saturday) — стандартная сериализация `System.Text.Json`.  
Пустой список — допустимое значение: ни один день не генерируется автоматически.

## Шаг 2 — `SettingsViewModel.cs`: чекбоксы дней

**Файл:** `Presentation/ViewModels/SettingsViewModel.cs`

### 2.1 Добавить вспомогательный класс в конец файла (или отдельный файл)

```csharp
public sealed class DayOfWeekItem : ViewModel
{
    public DayOfWeek DayOfWeek { get; init; }
    public string Name { get; init; } = "";

    private bool _isSelected;
    public bool IsSelected
    {
        get => _isSelected;
        set => Set(ref _isSelected, value);
    }
}
```

### 2.2 Добавить свойство в `SettingsViewModel`

```csharp
public ObservableCollection<DayOfWeekItem> AutoGenerateDayItems { get; }
```

### 2.3 Инициализировать в конструкторе (после `_minimumHoursText = ...`)

```csharp
var selected = new HashSet<DayOfWeek>(Editable.AutoGenerateDays);

AutoGenerateDayItems = new ObservableCollection<DayOfWeekItem>(
    Enumerable.Range(0, 7)
        .Select(i => (DayOfWeek)i)
        .Select(dow => new DayOfWeekItem
        {
            DayOfWeek = dow,
            Name = culture.DateTimeFormat.GetDayName(dow),
            IsSelected = selected.Contains(dow)
        }));
```

### 2.4 В методе `ApplyChanges()` — добавить синхронизацию (перед `_settings.Save()`)

```csharp
target.AutoGenerateDays = AutoGenerateDayItems
    .Where(x => x.IsSelected)
    .Select(x => x.DayOfWeek)
    .ToList();
```

### 2.5 В методе `Clone()` — скопировать список

```csharp
AutoGenerateDays = new List<DayOfWeek>(source.AutoGenerateDays),
```

## Шаг 3 — `SettingsDialog.xaml`: секция с чекбоксами

**Файл:** `Presentation/Windows/SettingsDialog.xaml`

Вставить **перед** блоком выбора языка (`<!-- Language selection -->`):

```xml
<!-- Auto-generate days -->
<TextBlock Text="{DynamicResource Settings_AutoGenerateDays}"
           Margin="0,10,0,4"/>
<ItemsControl ItemsSource="{Binding AutoGenerateDayItems}">
    <ItemsControl.ItemsPanel>
        <ItemsPanelTemplate>
            <WrapPanel/>
        </ItemsPanelTemplate>
    </ItemsControl.ItemsPanel>
    <ItemsControl.ItemTemplate>
        <DataTemplate>
            <CheckBox Content="{Binding Name}"
                      IsChecked="{Binding IsSelected}"
                      Margin="0,0,10,4"/>
        </DataTemplate>
    </ItemsControl.ItemTemplate>
</ItemsControl>
```

Также увеличить `Height` окна с `500` до `560` (добавилась секция ~60px).

1. `dotnet build DutyPlanner.sln` — убедиться, что сборка чистая.
2. Запустить приложение, открыть Настройки — секция дней видна, пятница и суббота отмечены.
3. Снять отметку «Суббота», сохранить. Добавить новый месяц — должны создаться только пятницы.
4. Убрать все отметки — при добавлении месяца дни не создаются.

## Примечания

- Название дней недели (`GetDayName`) отображается на **текущем языке** — поскольку `CultureInfo`
  берётся из `Editable.Language` в конструкторе `SettingsViewModel`, дни будут на языке,
  установленном до открытия настроек. Это поведение аналогично выпадающему списку месяцев — приемлемо.
- Порядок дней в `ItemsControl` — воскресенье…суббота (системный порядок `DayOfWeek`).
  При необходимости можно переупорядочить по локали, но это усложнение не обязательно.
- `AutoGenerateDays` **не** влияет на ручное добавление дня через `AddDayCommand` — это намеренно.
